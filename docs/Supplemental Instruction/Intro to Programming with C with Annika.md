⊹˚. ♡.𖥔 ݁ ˖ [**Geeks4Geeks Practice Questions**](https://www.geeksforgeeks.org/explore?page=1&sortBy=submissions) – A great website to use for coding practice! You can compile and run code within the website itself if you make a free account. You can also just look at them without signing in if you’d like. Reviewing the problems, I would say the Basic and Easy level problems are solvable with Intro to C level knowledge.

⊹˚. ♡.𖥔 ݁ ˖ **AI (Claude specifically)** – While you should **NEVER** use AI for the purpose of finding answers, a fellow SI leader told me that Claude’s model is _generally_ _decent_ at creating practice problems – although the chances of it getting something wrong/hallucinating aren’t zero. Just be wary!

⊹˚. ♡.𖥔 ݁ ˖ **[Dr. Guha’s Website](https://www.cs.ucf.edu/~dmarino/ucf/transparency/cop3223/)** – It might not be as pretty as the other options nor does it have solutions to double check your work against, but Dr. Guha’s website is an excellent resource for more problems. I would recommend checking out every hyperlink here – the “Friday Problems” are good, shorter problems whereas the assignments are more like, well, _assignments_. Just ignore the .py problems as we aren’t using Python in this course (Very sad, I know.) Another reason I would recommend his website is he is like, **THE GUY who makes assignments for CS1** courses **AND problems for the Foundation Exam!** This is the closest you can get to the style of questions you’ll see in the future, but about subjects you are currently learning!
